# WW2 Interactive Map

Интерактивная 2D-карта событий Второй мировой войны (сентябрь 1939 — сентябрь 1945, 73 месяца).

## Запуск без сервера (`file://`)

Откройте файл `index.html` напрямую в браузере двойным щелчком с диска (`file:///.../index.html`):
- Приложение **не использует `fetch()` к локальным JSON/GeoJSON** и не требует локального HTTP-сервера или сборки.
- Библиотека **Leaflet 1.9.4** (`vendor/leaflet/`) и все исторические данные (`data/*.js`) подключаются локально через `<script>`.
- В офлайн-режиме отображается полная векторная политическая карта мира 1939 года, крупные реки, линии фронта и все сражения. При наличии интернета можно включить/выключить опциональную физическую рельефную подложку без современных границ (`Esri World Shaded Relief`).

## Основные возможности

1. **Таймлайн войны (73 месяца: IX.1939 — IX.1945)**:
   - Ползунок по месяцам, кнопки пошагового перехода (`◀` / `▶`, клавиши `←` / `→`), автопроигрывание (`1×` / `2×`) и быстрые переходы к ключевым датам.
   - Помесячное обновление контроля стран и регионов (включая раздел Польши, зону Виши, оккупацию Европы, разделение Италии, наступление в СССР, Китае, Тихом океане и зоны оккупации 1945 г.).
   - Анимированные линии фронта на главных ТВД и географически обрезанные по суше зоны оккупации.

2. **База ключевых сражений (70 битв по всем ТВД)**:
   - Фильтрация по театрам военных действий и поиск по всем сражениям.
   - При нажатии на маркер битвы или её название в списке открывается подробная карточка: стороны, командующие, силы сторон, потери, итог и историческая сводка.

3. **Детальный тактический режим (6 главных битв)**:
   - **Битва за Москву** (1941–1942)
   - **Сталинградская битва** (1942–1943)
   - **Курская битва** (1943)
   - **Битва за Мидуэй** (1942)
   - **Высадка в Нормандии** (1944)
   - **Битва за Берлин** (1945)
   - Плавный зум (`flyTo`) на поле сражения, кликабельные значки армий/корпусов/флотов с карточкой соединения (командующий, состав, боевая задача), стрелки ударов, локальная линия фронта/котлы, нижний пошаговый таймлайн фаз и кнопка возврата к глобальной карте мира.

## Структура проекта

- `index.html` — точка входа (`file://` ready)
- `vendor/leaflet/` — локальная копия Leaflet 1.9.4
- `data/world_1939.js` — векторные границы мира на сентябрь 1939 г., реки и обрезанные по суше зоны оккупации
- `data/timeline_events.js` — 73 помесячных состояния контроля стран, сводки и линии фронта
- `data/battles.js` — 70 ключевых сражений Второй мировой войны
- `data/tactical_battles.js` — 6 детальных тактических операций с фазами, войсками и стрелками ударов
- `src/` — логика состояния (`state.js`), картографический движок (`map_engine.js`), тактический рендерер (`tactical_engine.js`), интерфейс (`ui.js`, `app.js`)
- `scripts/build_world_1939.py` — генератор исторической векторной карты из `historical-basemaps` и Natural Earth
- `tests/` — модульные тесты (`npm test`) и браузерные E2E-тесты через `file://` (`npm run test:e2e`)
